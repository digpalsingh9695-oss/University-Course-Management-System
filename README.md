# 🎓 University Course Management System

## 📌 Project Overview

The **University Course Management System** is a SQL-based database project developed using **PostgreSQL**. The main objective of this project is to organize and manage university-related information in a structured and efficient way.

A university handles different types of information, including student records, instructor details, departments, courses, and student enrollments. Managing this information manually can be time-consuming and may lead to data duplication and errors.

This project demonstrates how a relational database can be used to store, retrieve, update, and delete university data using SQL queries.

## 🎯 Project Objectives

- To understand relational database management using PostgreSQL.
- To create and manage tables for a university database.
- To store student, instructor, department, course, and enrollment information.
- To perform CRUD operations using SQL.
- To establish relationships between tables using primary keys and foreign keys.
- To practice writing SQL queries for database management and data retrieval.

## 🛠️ Tools and Technologies

- **Database:** PostgreSQL
- **Query Language:** SQL
- **Database Tool:** pgAdmin

## 🗂️ Database Structure

The project is designed around the following university-related entities:

- **Students:** Stores student information, such as names, email addresses, birth dates, and enrollment dates.
- **Instructors:** Maintains information about university instructors.
- **Departments:** Stores information about academic departments.
- **Courses:** Maintains course details and their associated departments.
- **Enrollments:** Connects students with courses and records enrollment dates.

*The exact columns and relationships depend on the tables implemented in the SQL file.*

## 🔄 SQL Operations Performed

### 1. CREATE
Used to create the database tables and define their columns, data types, and constraints.

### 2. INSERT
Used to insert records into tables, such as student details, course information, and enrollment records.

### 3. SELECT (READ)
Used to retrieve data from tables. Queries can display records, filter results, and retrieve specific information.

### 4. UPDATE
Used to modify existing records when information needs to be changed.

### 5. DELETE
Used to remove selected records from a table using specified conditions.
